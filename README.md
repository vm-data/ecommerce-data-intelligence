# E-commerce Data Intelligence Platform

## Project Overview
An end-to-end data engineering and analytics platform built
using the Brazilian E-Commerce Public Dataset by Olist.

## Objectives
- Ingest e-commerce data from multiple sources.
- Store raw and processed datasets.
- Build reliable data transformation pipelines.
- Analyze sales, products, customers, and delivery performance.
- Create dashboards and machine learning models.

## Technology Stack
- Python
- Git and GitHub
- Docker
- PostgreSQL
- MinIO
- Apache Airflow
- dbt
- Apache Spark
- Apache Kafka
- Scikit-learn
- Metabase

## Dataset
Brazilian E-Commerce Public Dataset by Olist.
